# Music Control Android

Mixer de áudio com cinco canais independentes, seleção de arquivos locais, volume por canal e reprodução em segundo plano.

## Gerar APK
O workflow **Android APK** compila automaticamente o aplicativo a cada push na branch `main`. O APK de depuração fica disponível em **Actions → Android APK → Artifacts**.

## Recursos
- Cinco canais de áudio simultâneos
- Seleção de arquivos do dispositivo
- Play, pause e stop por canal
- Volume individual e volume geral
- Serviço Android em primeiro plano para manter a reprodução com a tela bloqueada
- Notificação com controles de reprodução

O APK inicial é de depuração (`debug`) e serve para instalação e testes.
